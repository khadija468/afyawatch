# Data sources

AfyaWatch holds aggregate counts only. There are no patient-level records anywhere in the system.

| File / origin | Type | Content | Source and terms |
| --- | --- | --- | --- |
| `regions_census_2022.csv` | Public reference | Population of the 26 regions of Tanzania Mainland, 2022 Population and Housing Census (total 59,851,347) | National Bureau of Statistics (NBS), Tanzania, 2022 PHC. Figures read from https://www.citypopulation.de/en/tanzania/admin, which cites NBS. Public statistics; cite NBS. Region codes follow ISO 3166-2:TZ. |
| `campaign_metrics_export.csv` | Synthetic | Daily impressions, reach, engagements, link clicks and shares per platform for a measles-rubella catch-up campaign, 7 Sep to 22 Nov 2026 | Generated for this project in the layout of a social media analytics export. Free to use. |
| Facility weekly reports (generated by `SurveillanceDataSeeder`) | Synthetic | Cases and deaths per facility, condition and ISO week (52 weeks to week 47 of 2026); MR1 and Penta3 doses per facility per month | Generated with a fixed random seed so every install produces the same data. Shaped like the IDSR weekly reporting form. Free to use. |

## Assumptions

- Surviving infants (the denominator for immunization coverage) are estimated as 3.5% of each region's 2022 population. Replace this with the immunization programme's official target population when available.
- Facility names are invented (for example "Kigoma Health Centre 2") and do not refer to real facilities.
- Outbreaks were placed in the synthetic data on purpose so that alerts can be demonstrated: cholera in Kigoma (weeks 44 to 47) and measles in Kagera (weeks 41 to 47), both in 2026.
